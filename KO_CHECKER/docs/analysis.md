# RNA評価と出力仕様

## 解析エンジン

Web版は`pipeline.py`でデータ取得・マッピングを行い、`rnako.py`のエンジン（0.1.2）にSRX単位のBAMを渡します。以下のRNA判定は、入力ラベルが正しいかを配列の証拠から検討するための暫定評価です。DNAのKO成立やタンパク質消失を確定しません。

リードは未マッピング、secondary、supplementary、重複フラグ付き、QC失敗を除外します。`NH`タグがある場合は`NH=1`を要求し、ない場合はMAPQ 20以上を要求します。BAMの既存フラグを参照する処理であり、Webパイプラインで重複マーキングを追加する機能はありません。

WebのBAM作成はpipeline version 2です。prefetch → vdb-validate → fasterq-dump（split-files）→ fastp → HISAT2 → samtools sort / quickcheck / indexの順に処理します。fastpは標準のアダプタ除去・品質／長さフィルタ、PEでは`--detect_adapter_for_pe`を適用します。HISAT2は`-k 100 --secondary`、PEでは`--no-mixed --no-discordant`、非ストランド指定です。`--dta`は使いません。元のFASTQと、前処理済みFASTQ・HTML/JSONのQCを保持します。多重マッピングを含むBAMを作成しますが、以下のKO評価と発現指標のリード選別は維持します。TEの多重マッピング定量は行いません。

前処理済みキャッシュは元FASTQのfingerprint・fastpバージョン・オプション、BAMは変換／前処理ツール・マッピング設定・参照索引を照合します。旧版の未前処理BAMは保持し、新版の解析に流用しません。`provenance.json`に工程・前処理ファイル・QCパス・実使用スレッド数を記録します。fastpの実使用スレッド数は同梱版の上限16までです。QCのJSONが不完全、出力が不足、またはフィルタ後0リードの場合は完成として扱いません。

発現量はエクソン上のユニーク断片数を、ライブラリ全体の有効断片数で補正したCPMです。TPMや転写産物単位の存在量ではありません。遺伝子内・接合部の計数ではリード名をまとめて断片として数えます。

## 主な閾値

Web版ではCLIの既定値を使用します。

| CLIオプション | 既定値 | 主な用途 |
| --- | ---: | --- |
| `--min-mapq` | 0 | NHがある場合のMAPQ下限。NHがない場合は最低20 |
| `--min-bq` | 20 | 変異位置の塩基品質 |
| `--min-alt` | 3 | 変異候補の最低支持リード数 |
| `--min-af` | 0.05 | 変異発見の局所支持率下限、WT-like判定の異常率上限 |
| `--min-junction` | 3 | 接合部の最低支持断片数 |
| `--min-delta` | 0.2 | 比較側の最大支持率に対する差 |
| `--min-ko-af` | 0.4 | KO-like根拠にする変異・スキップの支持率 |
| `--min-event-depth` | 10 | 比較検体の変異位置や局所接合部などに要求する深度 |
| `--min-gene-fragments` | 20 | 遺伝子内の最低有効断片数 |

変異によるKO_likeは、比較側より濃縮された候補にフレームシフト・早期終止・開始コドンへの影響などが予測される場合です。スキップの根拠は、未注釈で既存エクソンを飛ばし、支持数・局所分母・支持率・比較側との差を満たし、コード領域のタンパク質変化や開始領域の欠落を予測する接合です。スキップはフレーム内の予測でも根拠になり得ますが、予測タンパク質が変わらないUTRだけのスキップは根拠にしません。

比較側にはWTラベルの検体を優先し、自分以外にWTがない場合は他検体を使用します。入力ラベルを自動的に確定するものではありません。遺伝子内の断片不足の場合は判定を保留します。

WT_likeには、他検体のKO-like候補位置を十分に読めて異常率が低いこと、または条件を満たす正常接合の証拠が必要です。観測できない位置の異常や、他の種類の損傷は否定できません。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `output/samples.csv` | SRXごとの指定ラベル、RNA判定と理由、断片数、CPM、WT基準比、カバレッジ注意 |
| `output/events.csv` | 検出閾値を満たしたSNV・短い挿入/欠失、位置、支持リード、局所変異率、比較結果 |
| `output/observations.csv` | 発見された候補変異位置を全検体で再観測した深度・支持数・局所変異率。Webパイプラインが追加生成 |
| `output/junctions.csv` | スプライス接合部、支持断片、注釈の有無、スキップ対象、局所支持率と比較 |
| `output/consequences.csv` | イベント×転写産物の予測タンパク質、変異の影響、終止位置、NMD距離指標 |
| `output/run.json` | エンジンバージョン、対象、参照パス、実際の閾値 |
| `output/conclusion.txt`、`output/conclusion.json` | 配列・発現量・エクソン・NMDをまとめた結論と、発現比較の値・検定条件 |
| `provenance.json` | 入力SRXとrunの対応、ツールのバージョン情報、マッピング条件、参照ファイル情報 |

表の結合には`srx_id`と`event_id`を使います。Web表示は各表の先頭1,000行までです。ダウンロードできるCSVには全行を保存します。既存`events.csv`には候補として検出された行だけがあり、未掲載は変異率0%を意味しません。`observations.csv`は0支持と深度不足を区別します。

## 冒頭の結論と発現量の比較

配列評価・発現量・局所的なエクソン低下・NMDの解釈を、詳細表の前にまとめます。配列が判定保留でも、発現量の低下率は独立して報告します。発現量のWT基準は、WT指定でライブラリ有効断片数が正かつCPMが有効な全検体の平均です。`WT_like`であることは要求しません。対象遺伝子が低発現・0支持のKO検体も、ライブラリ計数が有効なら比較に含めます。WT平均が0なら比や低下率は計算せず、その理由を表示します。低下率は`100 × (1 − KO平均CPM / WT平均CPM)`です。

Webの反復確認オプション、またはCLIの`--confirm-replicates`が明示され、各群2検体以上の有効な独立反復がある場合にのみ、CPMの平均差の絶対値を統計量とする両側置換検定を行います。群ラベルが交換可能であることを仮定した探索的な検定です。全組合せが50,000通り以下なら全列挙し、それを超える場合は乱数seed 0で19,999回抽出します。全列挙のpは同等以上に極端な組合せの割合、乱数近似は`(該当数 + 1) / (19,999 + 1)`とし、0のpを返しません。未補正p < 0.05を探索的な有意差と表示します。単一遺伝子が対象で、エクソン別検定や解析をまたいだ多重検定補正は行いません。少数の反復ではpの分解能が粗く、検出力が低くなります。

SRX数やrun数から生物学的反復を自動確定しません。対応のあるデザイン・群とバッチの交絡・比較不可能な条件にはこの検定を使用できません。CPMに対する検定であり、組成補正・バッチ補正を伴うDESeq2等の全遺伝子解析とは異なります。発現低下率も絶対mRNA分子数や機能喪失率ではありません。

NMDの解釈は、KO群で比較側より濃縮された候補について、フレームシフト・早期終止・フレームシフトするスキップで`nmd_prediction=possible`となり、その同じ検体がWT平均より低発現、かつKO群全体も低下する場合に「関与と整合する」とします。機序の証明やNMDの統計検定ではありません。発現低下のみの場合は、NMDを含む分解促進と転写低下などを区別できないと表示します。

Webでは過去の結果のCSVを変更せず結論を生成し、`conclusion.txt/json`をダウンロードできます。表の先頭1,000行制限を適用する前の全CSVから結論を生成します。旧`samples.csv`の保存済みWT基準比と、現在の画面・結論の基準は異なる場合があります。

置換検定の参考: [SciPyの定義と再標本化p値](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html)。本実装の両側性は平均差の絶対値で定義します。

## エクソンのカバレッジ比較（Web版）

`exon_coverage.csv`は、全注釈転写産物のエクソンを同一座標でまとめ、検体ごとの断片数、平均・最低深度、深度1以上／10以上の塩基割合、最長ゼロ深度区間、エクソン全体をまたぐスプライス接合の支持断片数を保存します。番号は転写産物別に併記します。深度は既存のリード選別と塩基品質20以上を適用し、欠失・イントロンとして整列した部分を除きます。断片数と接合支持数には塩基品質による選別は適用しません。

WTとの比較では、各エクソンの平均深度を、対象エクソン以外の遺伝子内エクソン（全転写産物の和集合）の平均深度で割ります。同じエクソンと残りのエクソンのそれぞれで、深度10以上の塩基が80%以上あるWT検体だけを参照し、この相対深度のWT平均に対する比を報告します。WT参照がない場合は空欄にし、WTの深度不足と表示します。WT行は比較用検体として扱います。

KO検体の残りのエクソンも同じ深度基準を満たし、WT比が20%以下かつ対象エクソンで読まれた塩基が50%未満の場合に「局所的な読み取り低下の疑い」を表示します。それ以外で対象エクソンまたは他エクソンの深度が不足する場合は、検体の深度不足と表示します。これは探索用の基準で、統計的に検証された欠失検出器ではありません。疑い・読み取りなし・スキップ支持のいずれも、DNA上のエクソン欠損を確定しません。スキップ支持には既存アイソフォームも含まれます。`samples.csv`の既存RNA判定には影響しません。

gRNAの標的座標は自動取得しません。この表はエクソン単位の評価であり、エクソン内の特定の標的塩基が十分に読まれていることを保証しません。既知の標的位置は座標とBAMで別途確認してください。過去の結果にこのCSVがない場合も閲覧でき、再実行すると追加されます。

### RNA領域欠損を用いる追加判定（CLI・Web）

上記の従来の他エクソン補正に加え、`region_loss.py`はWTで十分読める各エクソンの平均深度をライブラリ断片数で補正して比較します。KO/WT比10%以下（または20%以下かつ読まれた塩基が50%未満）の領域と、同じ検体で保たれる内部対照領域（深度基準を満たしKO/WT比50%以上）が両方ある場合にRNA領域欠損を推定します。欠損領域自身の深度や、全エクソンの均一な深度は要求しません。

標準開始コドンを持つ最長CDSの開始領域喪失、または30塩基以上かつCDSの10%以上の喪失／フレームシフトをKO様の根拠として` samples.csv `に反映します。RNAの構造所見に基づく暫定分類で、DNA上の欠失やタンパク質機能消失の確定ではありません。既存の小変異・接合によるKO判定は保持します。

`region_deletions.csv`、`region_proteins.fasta`、`region_transcripts.fasta`は注釈境界でエクソンが除かれる条件付きモデルです。同じ転写産物の複数の減少エクソンをまとめて適用します。接合の支持がないモデル、末端不明の断片、開始領域が失われ翻訳開始が不明なモデルを区別します。代替開始や未知の末端塩基は創作しません。インフレーム欠損やアイソフォーム間の違いから実際の機能消失を断定しません。

## 座標表記

### 遺伝子構造図

`gene_structure.json`は注釈転写産物のエクソン/CDSと、参照cDNAの各塩基に対応するゲノム座標から開始・終止コドンの位置を計算します。図は常に5′→3′方向で、マイナス鎖ではゲノム座標が右へ減少します。接合をまたぐコドンは3塩基それぞれの座標を詳細表示します。イントロン短縮の模式図は小エクソンの最小幅も確保するため、距離に比例しません。非短縮モードは共通のゲノム座標軸です。

WTは参照注釈に観測深度・局所変異率を重ね、WTの実測コンセンサス配列とは区別します。KOでは領域欠損モデルまたは1変異モデルを選べます。欠損したエクソンを斜線で残して位置関係を示し、接合未確認のモデルを破線で表示します。予測終止位置を残存エクソンへ再投影し、未知の末端・開始位置は描きません。単一変異モデルは複数変異の位相を扱わず、参照座標を持たない挿入塩基は挿入のアンカー位置にマーカーを置きます。モデルのタンパク質長は条件付き予測で、実在・機能・量は確定しません。

- CSVのゲノム座標は1始まりです。
- `pos_1based`はSNVまたは挿入・欠失のVCF形式のアンカーです。
- `intron_start_1based` / `intron_end_1based`はスプライスされた区間の両端です。
- `stop_codon_cdna_1based`は転写産物上の終止コドン開始位置です。
- `stop_to_last_junction_nt`は終止コドン末端から最後のエクソン接合部までの距離です。正の値は終止が接合部の上流にあることを示します。

## 解釈上の制限

- `local_alt_fraction`は変異位置の有効リードに対する割合です。遺伝子全体の異常mRNA割合ではありません。`normal_mrna_fraction` / `abnormal_mrna_fraction`は未推定のため空欄です。
- `local_skip_fraction`の局所分母は左右の境界を共有する接合支持数の大きい方です。転写産物の存在割合ではありません。
- `predicted_protein`は注釈転写産物に1変異または1スキップだけを適用したモデルです。離れた変異はフェージングせず、実際に発現していない転写産物も含み得ます。
- NMD列は50〜55 ntの距離規則による予測です。RNA分解やタンパク質消失の実測ではありません。
- エクソンスキップからDNA上のエクソン欠失は断定できません。複雑な構造変異、末端欠落、低発現、繰り返し配列でのindel表現揺れなどは十分に扱えません。
- 単一変異の発見は簡易pileupです。包括的な変異コーラーの代替ではなく、候補はIGVや独立した実験で確認する必要があります。
- 群平均は相対発現量の記述です。有意差は反復・実験条件の確認を伴う探索的な置換検定を実施した場合にのみ表示します。CLIはKD/OEラベルも受け付けますが、その発現変化の妥当性は判定しません。
