# RNA評価と出力仕様

## 解析エンジン

Web版は`pipeline.py`でデータ取得・マッピングを行い、`rnako.py`の既存エンジン（0.1.1）にSRX単位のBAMを渡します。以下のRNA判定は、入力ラベルが正しいかを配列の証拠から検討するための暫定評価です。DNAのKO成立やタンパク質消失を確定しません。

リードは未マッピング、secondary、supplementary、重複フラグ付き、QC失敗を除外します。`NH`タグがある場合は`NH=1`を要求し、ない場合はMAPQ 20以上を要求します。BAMの既存フラグを参照する処理であり、Webパイプラインで重複マーキングを追加する機能はありません。

発現量はエクソン上のユニーク断片数を、ライブラリ全体の有効断片数で補正したCPMです。TPMや転写産物単位の存在量ではありません。遺伝子内・接合部の計数ではリード名をまとめて断片として数えます。

## 主な閾値

Web版ではCLIの既定値を使用します。

| CLIオプション | 既定値 | 主な用途 |
| --- | ---: | --- |
| `--min-mapq` | 0 | NHがある場合のMAPQ下限。NHがない場合は最低20 |
| `--min-bq` | 20 | 変異位置の塩基品質 |
| `--min-alt` | 3 | 変異候補の最低支持リード数 |
| `--min-af` | 0.05 | 変異発見の局所支持率下限、WT-like判定の異常率上限 |
| `--min-junction` | 3 | 接合部の最低支持断片数 |
| `--min-delta` | 0.2 | 比較側の最大支持率に対する差 |
| `--min-ko-af` | 0.4 | KO-like根拠にする変異・スキップの支持率 |
| `--min-event-depth` | 10 | 比較検体の変異位置や局所接合部などに要求する深度 |
| `--min-gene-fragments` | 20 | 遺伝子内の最低有効断片数 |

変異によるKO_likeは、比較側より濃縮された候補にフレームシフト・早期終止・開始コドンへの影響などが予測される場合です。スキップの根拠は、未注釈で既存エクソンを飛ばし、支持数・局所分母・支持率・比較側との差を満たす接合です。スキップはフレーム内の予測でも根拠になり得ます。

比較側にはWTラベルの検体を優先し、自分以外にWTがない場合は他検体を使用します。入力ラベルを自動的に確定するものではありません。遺伝子内の断片不足の場合は判定を保留します。

WT_likeには、他検体のKO-like候補位置を十分に読めて異常率が低いこと、または条件を満たす正常接合の証拠が必要です。観測できない位置の異常や、他の種類の損傷は否定できません。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `output/samples.csv` | SRXごとの指定ラベル、RNA判定と理由、断片数、CPM、WT基準比、カバレッジ注意 |
| `output/events.csv` | 検出閾値を満たしたSNV・短い挿入/欠失、位置、支持リード、局所変異率、比較結果 |
| `output/observations.csv` | 発見された候補変異位置を全検体で再観測した深度・支持数・局所変異率。Webパイプラインが追加生成 |
| `output/junctions.csv` | スプライス接合部、支持断片、注釈の有無、スキップ対象、局所支持率と比較 |
| `output/consequences.csv` | イベント×転写産物の予測タンパク質、変異の影響、終止位置、NMD距離指標 |
| `output/run.json` | エンジンバージョン、対象、参照パス、実際の閾値 |
| `provenance.json` | 入力SRXとrunの対応、ツールのバージョン情報、マッピング条件、参照ファイル情報 |
| `input_samples.csv` | エンジンへ渡した検体とBAMパス |
| `job.json`、`pipeline.log` | ジョブ状態、工程、コマンド、標準出力・エラー、再試行や例外の記録 |

表の結合には`srx_id`と`event_id`を使います。Web表示は各表の先頭1,000行までです。ダウンロードできるCSVには全行を保存します。既存`events.csv`には候補として検出された行だけがあり、未掲載は変異率0%を意味しません。`observations.csv`は0支持と深度不足を区別します。

## エクソンのカバレッジ比較（Web版）

`exon_coverage.csv`は、全注釈転写産物のエクソンを同一座標でまとめ、検体ごとの断片数、平均・最低深度、深度1以上／10以上の塩基割合、最長ゼロ深度区間、エクソン全体をまたぐスプライス接合の支持断片数を保存します。番号は転写産物別に併記します。深度は既存のリード選別と塩基品質20以上を適用し、欠失・イントロンとして整列した部分を除きます。断片数と接合支持数には塩基品質による選別は適用しません。

WTとの比較では、各エクソンの平均深度を、対象エクソン以外の遺伝子内エクソン（全転写産物の和集合）の平均深度で割ります。同じエクソンと残りのエクソンのそれぞれで、深度10以上の塩基が80%以上あるWT検体だけを参照し、この相対深度のWT平均に対する比を報告します。WT参照がない場合は空欄にし、WTの深度不足と表示します。WT行は比較用検体として扱います。

KO検体の残りのエクソンも同じ深度基準を満たし、WT比が20%以下かつ対象エクソンで読まれた塩基が50%未満の場合に「局所的な読み取り低下の疑い」を表示します。それ以外で対象エクソンまたは他エクソンの深度が不足する場合は、検体の深度不足と表示します。これは探索用の基準で、統計的に検証された欠失検出器ではありません。疑い・読み取りなし・スキップ支持のいずれも、DNA上のエクソン欠損を確定しません。スキップ支持には既存アイソフォームも含まれます。`samples.csv`の既存RNA判定には影響しません。

gRNAの標的座標は自動取得しません。この表はエクソン単位の評価であり、エクソン内の特定の標的塩基が十分に読まれていることを保証しません。既知の標的位置は座標とBAMで別途確認してください。過去の結果にこのCSVがない場合も閲覧でき、再実行すると追加されます。

## 座標表記

- CSVのゲノム座標は1始まりです。
- `pos_1based`はSNVまたは挿入・欠失のVCF形式のアンカーです。
- `intron_start_1based` / `intron_end_1based`はスプライスされた区間の両端です。
- `stop_codon_cdna_1based`は転写産物上の終止コドン開始位置です。
- `stop_to_last_junction_nt`は終止コドン末端から最後のエクソン接合部までの距離です。正の値は終止が接合部の上流にあることを示します。

## 解釈上の制限

- `local_alt_fraction`は変異位置の有効リードに対する割合です。遺伝子全体の異常mRNA割合ではありません。`normal_mrna_fraction` / `abnormal_mrna_fraction`は未推定のため空欄です。
- `local_skip_fraction`の局所分母は左右の境界を共有する接合支持数の大きい方です。転写産物の存在割合ではありません。
- `predicted_protein`は注釈転写産物に1変異または1スキップだけを適用したモデルです。離れた変異はフェージングせず、実際に発現していない転写産物も含み得ます。
- NMD列は50〜55 ntの距離規則による予測です。RNA分解やタンパク質消失の実測ではありません。
- エクソンスキップからDNA上のエクソン欠失は断定できません。複雑な構造変異、末端欠落、低発現、繰り返し配列でのindel表現揺れなどは十分に扱えません。
- 単一変異の発見は簡易pileupです。包括的な変異コーラーの代替ではなく、候補はIGVや独立した実験で確認する必要があります。
- 群平均は記述的な表示です。群間の有意差検定はしません。CLIはKD/OEラベルも受け付けますが、その発現変化の妥当性は判定しません。
