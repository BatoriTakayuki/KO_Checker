# Changelog

## CPU threads — 2026-10-17

- 解析ごとにCPUスレッド数（1〜256）を指定できるオプションを追加。空欄は既定値を使用。
- 中断・再開と同条件の再実行で設定を引き継ぎ、実使用値を解析タイトル・ログ・provenance.jsonに記録。

## Integrated update — 2026-10-17

- Windowsのダブルクリック起動、中断・再開、遺伝子名の大文字・小文字補完、エクソン比較を統合。
- エクソン比較の計算中も中断でき、前回の完成済み比較CSVは保持。
- リリースZIPと作業フォルダのSHA256SUMS.txtを同時に更新。
- Web結果とCSVにエクソン単位のカバレッジ・WT比較・スキップ接合支持を追加。深度不足と局所的な読み取り低下の疑いを区別し、既存のRNA判定は維持。
- 遺伝子名が完全一致しない場合、大文字・小文字を無視した一意な一致も検索（例：マウスのZFP445 → Zfp445）。
- prefetchがrun名のフォルダを二重に作成した場合も、取得済みSRAを検出してFASTQへ変換できるよう修正。
- Docker内の43テスト（中断・再開、HTTP Range、人工BAMによるエクソン比較、遺伝子名補完、旧結果互換性）が成功。

## Progress and pause/resume — 2026-10-17

- Web画面に中断・同一ジョブの再開、参照・索引完成後の自動中断を追加。
- サーバー再起動で中断されたジョブを失敗と区別して復元。
- 参照取得でHTTP RangeとIf-Rangeを使い、配信元の同一内容を確認した上で部分取得を再利用。
- 取得容量・速度・ファイル単位の残り時間、実行時間・run完了数・工程・最新ログを表示。
- SRA取得・整合性検査・FASTQ変換、参照取得・展開・索引を区別して表示。
- 中断時に外部コマンドのプロセスグループを終了。完了済みの索引やBAMの再利用条件は維持。
- ローカルHTTPサーバー、実子プロセス、Web APIを使った中断・再開テストを追加。

## Download path fix — 2026-10-17

- prefetchが指定出力先の下にもう一段run名のフォルダを作る場合、取得成功後にSRAを見つけられない不具合を修正。
- 直下・入れ子の保存先について、SRA Normalized / SRA Liteの両形式を検査する回帰テストを追加。

## Web prototype — 2026-10-16

- SRX / ERX / DRXをWT群・KO群ごとに複数入力できるWeb画面を追加。
- ENAでrunを解決し、SRA Toolkitで取得・FASTQ変換する処理を追加。
- HISAT2・samtoolsによるマッピング、run間のリード名衝突を避けるSRX単位のBAM統合を追加。
- 完了済み参照・索引・FASTQ・BAMの再利用に対応。
- ジョブ履歴・工程表示・ログ・CSVの表・CPM等のグラフを追加。
- 全検体の候補位置再観測を`observations.csv`へ記録。
- ENAの一時障害への再試行と検索APIへの切り替え、例外ログを追加。
- GitHub共有用README、データ除外設定、Dockerテスト用CI、ソースのみのZIP作成スクリプトを追加。

既存のRNA判定エンジンは`rnako.py`の0.1.1です。Web層の追加に伴う判定ロジックの変更はありません。

## RNA evidence engine 0.1.1

- 低頻度の未注釈スキップだけでKO_likeとなる問題を修正。
- 局所的なスプライス支持率、比較検体のカバレッジ、支持率差を判定に使用。
- 検体順に依存しない判定、BAMとFASTAの染色体名の別名解決と長さ照合をテスト。
