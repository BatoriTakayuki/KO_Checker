# KO_Checker
KO_Checkerは、公開RNA-seqデータからノックアウト（KO）を支持するRNA上の証拠を探索する研究用ツールです。ブラウザで対象遺伝子とWT・KO群のSRX番号を入力すると、データ取得、HISAT2によるマッピング、変異・スプライス接合の解析を自動実行します。発現量やエクソンごとのカバレッジを比較し、読み取り不足と局所的な読み取り低下の疑いを表示します。解析の中断・再開、データの再利用、CPUスレッド数の指定、結果CSVの出力に対応。Docker環境で動作し、Windowsではダブルクリックで起動できます。RNA上の暫定評価を目的としており、DNA上のKO成立やタンパク質消失を確定するものではありません。
